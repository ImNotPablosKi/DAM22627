# Practica 03 - Flutter

## Como abrirlo en VSCode
1. Descomprime la carpeta y abrela con VSCode (File > Open Folder).
2. En la terminal ejecuta (una sola vez, crea las carpetas android/ios/etc.):
   flutter create .
3. Ejecuta:
   flutter pub get
4. Pulsa F5 o ejecuta: flutter run

## Antes de entregar
flutter clean   (y luego comprimir)
